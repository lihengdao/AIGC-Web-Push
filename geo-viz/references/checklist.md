# 地理镜头交付检查

本清单按实际使用的引擎执行，不要求未使用的组件通过不适用项目。

## 项目与数据
- [ ] 写新渲染代码前已查 `projects.md` 和对应官方示例。
- [ ] 已复用适用的 Remotion/MapLibre 模板；实验项目经过本地 POC 才进入正式制作。
- [ ] 没有把未安装、未测试的项目描述为已集成或生产可用。
- [ ] 每份数据资产在 manifest 中记录来源、版本/日期、许可、CRS、bbox、分辨率、垂直基准（如适用）和归属。
- [ ] 历史路线/疆域经过独立核验，不是直接套用现代 OSM。
- [ ] 公共瓦片/API 的下载、缓存、并发和离线使用符合当前条款。

## 渲染与确定性
- [ ] 最终渲染使用已准备好的本地/获准数据；没有逐帧临时下载或查询公共 API。
- [ ] 动画由 Remotion frame 或 HyperFrames seek 驱动。
- [ ] 若使用 MapLibre WebGL：已采用 `preserveDrawingBuffer: true`、`--gl=angle`，并按官方 technique 等待初始化和每帧更新完成。
- [ ] 若使用 MapLibre：已检查 `interactive: false`、`fadeDuration: 0` 等非确定性设置；未随意添加会干扰渲染生命周期的 `map.remove()` cleanup。
- [ ] 若使用逐帧地图相机：已先导出短 MP4，检查 shimmer、闪烁、抖动和标签重排；不稳定就改固定地图板/叠层动画。
- [ ] MapLibre GPU 渲染从 `--concurrency=1` 验证；提高并发前已重复测试。
- [ ] 同一帧和同一短片的重复渲染结果一致。
- [ ] HyperFrames 使用完整预烘焙底图，不在渲染时请求在线瓦片。

## 画面与事实
- [ ] 主体、地理关系、路线转折和必要标签清楚易读。
- [ ] 地形纹理/相机距离与实际 DEM、影像分辨率相符。
- [ ] 无空白瓦片、黑块、意外接缝、闪帧、相机抖动或缺失资源。
- [ ] AI 生成资产或示意模型没有冒充真实卫星、实测地形或真实建筑。
- [ ] 画幅遵循用户要求；竖屏/横屏各自构图，没有擅自更改输出比例。
- [ ] 画面不是无叙事作用的信息卡轮播；每个镜头有可理解的对象、变化或空间关系。

## 最终文件
- [ ] 已导出短 MP4 或最终 MP4，而不只是查看网页预览。
- [ ] 抽查开场、中段、关键动作和结尾帧；完整播放并检查音画同步。
- [ ] 许可证、署名和历史事实要求已核对。
