# 运镜与完整画面

宿主视频规范中的镜头叙事对地理镜头同样生效：每次运动都要揭示空间信息；主段由对象、可见变化和结果推动。本文件只规定地理镜头的运镜、尺度和完整性要求，不规定每个镜头都必须三维或使用卫星纹理。

## 先确定镜头任务

先明确本镜要让观众看见什么地点、对象或空间关系，再选择镜头。地图相机运动不是目的；静态地图板加路线、区域、标签动画通常更稳定，也完全可以是合格镜头。

| 场景 | 可见变化 | 镜头选择 | 避免 |
| --- | --- | --- | --- |
| 行政区定位 | 目标区域从整体中被识别 | 固定地图板上逐步高亮；必要时短推近 | 无意义空转或全量标签挤屏 |
| 地球与航线 | 目标半球、起终点和航线关系被看懂 | 稳定对准相关半球，弧线按帧生长 | 地球自行播放、航线突然闪现 |
| 平面路线 | 路线方向和关键节点清楚 | 固定地图板 + 路线揭示；必要时短距离跟随 | 无目的平移、缩放或持续跟车 |
| 城市路网 | 关键道路或区域被揭示 | 以局部区域为主，简化非重点道路 | 把全量路网堆满画面 |
| 建筑体量 | 建筑足印逐步长成街区体块 | 先俯视看生长，再按需降低视角 | 少量方块冒充真实城市 |
| 三维地形 | 山脉走向、河谷或盆地关系清楚 | 选俯视、斜视或轻轨道；控制高度夸张 | 过度夸张、数据撑不起的近景 |
| 地形剖面 | 高程变化与剖面位置对应 | 沿剖面线逐步揭示 | 把不同垂直基准的数据混在一起 |
| 多尺度定位 | 每次切换带来新的空间信息 | 在数据完整的尺度层级间切换 | 从太空无缝钻到未准备的街道级别 |
| 行人/交通工具跟随 | 对象沿可靠路线前进 | 仅在有跟随价值时做平滑跟拍 | 折线尖角导致镜头急甩 |
| 流域/河网 | 主干、支流和流域范围区分 | 主干逐步揭示，其他河网降权 | 全网同权造成视觉噪声 |
| 宇宙/行星 | 天体位置或尺度关系被看懂 | 稳定绕行或按主题切换 | 无目的翻滚、伪装精确星历 |

## 跟随类镜头

只有确实需要展示沿途过程时才使用跟随镜头：

1. 路径先做几何校验，必要时按弧长重采样；不能把不连续碎路段拼成长线。
2. 对象位置按路径进度插值；朝向看向前方一小段路径，避免对准每个折线尖角。
3. 相机位置、缩放、偏航由帧号确定；阻尼也必须按帧计算，不能使用真实时间或墙钟。
4. 路径绕远、折返或几何异常时先修正路线；不能带着错误路线做镜头平滑。

## 底图和瓦片完整性

- 最终渲染所需的底图、影像、地形和模型必须预先准备，或来自获准且稳定的自托管源；不能在逐帧渲染时临时请求公共瓦片。
- MapLibre 地图使用 `delayRender()` / `continueRender()` 等待初始化和帧更新；具体 WebGL 设置遵循 `remotion.md` 与 Remotion 官方 MapLibre technique。
- HyperFrames 只使用预烘焙并完整检查的底图，不在出帧时加载在线瓦片。
- 检查开场、中段和结束帧：不能有黑块、空瓦片、接缝闪烁、标签重排或资源未加载。

## 数据尺度与相机距离

不要在规则里假定全球所有 DEM 或影像具有相同分辨率。镜头距离以本片资产 `manifest.json` 记录的实际分辨率、覆盖范围、数据类型和纹理清晰度为准：

- DSM、裸地 DEM、海底地形和卫星影像的含义不同，不得混称。
- DEM 的网格间距不等于最终画面可辨识的地形细节尺度；插值不能创造真实细节。
- Sentinel-2、Blue Marble 等产品适合各自分辨率下的区域/全球表达，不是街景或高清航拍素材。
- 细节不足时拉远、切换层级、换用剖面/平面示意，或取消该镜；不要假装是近距离实拍。

## 画幅和文字

- 严格遵循用户要求的横屏/竖屏比例。竖屏空间不足时，在指定比例内重新构图、分段展示或减少同时出现的信息；只有用户明确需要时才另做其他比例版本。
- 地形上的立体文字难读时改用屏幕平面标签；标签应避让字幕和关键地理对象。
- 不必强行让地形或地图铺满整个画面；留白可以是构图，但不能掩盖缺瓦、裁切错误或模型不完整。

## 换方案条件

代表帧出现残缺底图、明显抖动、发塑料、发糊、体块冒充真实建筑或整体不适合成片时，不继续硬渲。按 `quality.md` 和 `fallbacks.md` 改用该镜对应的更可靠表达，再检查真实 MP4。
