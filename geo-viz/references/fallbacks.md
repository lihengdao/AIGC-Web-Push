# 什么情况下必须换表达

先按 `quality.md` 与 `scenes.md` 做。表上没有的场景同样适用。若这一镜本来就会不清晰、粗糙、抖动、缺瓦、发糊、发塑料，或名不副实、达不到能给观众看的完成度，不要硬做。按下表改表达，再检查是否合格。换了之后仍须运镜有目的、对象有可见变化、底图完整，并符合 `quality.md`。

| 原定场景 | 出现这些情况就不要硬上 | 改用的表达 |
| --- | --- | --- |
| 行政区立体图 | 省名大量出画或互相重叠；镜头顾此失彼；挤出高低看不出主题 | 改平面行政区，或只突出主题省/地区，其余弱化。不要把全部地名硬塞进画面 |
| 样式化地球与航线 | 弧线过密、主题半球被挡住；用 three-globe 时钟导致进度对不上或闪动 | 只保留主题航线，相机稳住对准相关半球。出片改用 Three.js + Turf `greatCircle` 按帧写进度 |
| 卫星地球 | 推得过近发糊、发黑或露出空纹理 | 停在概览纹理仍然清楚的距离，或切到平面图、省级立体图。不要假装是街景卫星 |
| 平面行政区 | 地级界和地名挤成一团，读不清 | 升一级只示省界，或只放大主题区域。不要全量标注 |
| 城市平面图 | 缺瓦、黑块；路网过密成一团 | 改用已完整的本地矢量，并简化或缩小范围。不要边渲边拉在线瓦片 |
| 建筑生长 | 一两栋楼挡满画面；体块看上去像硬凑的真实城市；没有足印数据 | 拉远看整片街区，并按 LOD1 体块来拍、来写。没有足印就改城市平面图，不要用几个方块冒充城市 |
| 行人 A→B（三维跟随） | 路径折返、绕远、镜头左右甩，或人物在尖角上抢转 | 用 OSRM 重算并平滑后再拍。仍不稳就改「平面导航 / 轨迹」，不要带着抖动交片 |
| 平面导航 / 轨迹 | 底图残缺；折线杂乱；仿成商业导航界面却很像假的 | 只用完整本地底图和一条干净分色路线。仍不好就改成北朝上的路线生长图，不要模仿高德或百度界面 |
| 飞机 A→B / 大圆 | 看不清起点或终点；弧飞出画面 | 先稳住看清整段大圆，再切近景跟随。不要伪造航空公司界面或某次航班 |
| 行程与热力 | 中文标签发虚、热力脏、看不出主题 | 以点和弧为主，地名改用 MapLibre 或 Three 标签。数据不够就不要上热力层 |
| 多尺度 | 连续推近后中间出现空白、马赛克或突然没细节 | 在数据已经准备好的层级之间切换或停住，不要从太空一直钻到街道 |
| 地形、钉点、地名 | 垂直夸张失控；钉子和字叠成一团 | 降低夸张、减少同时出现的点，或改成平面定位图 |
| 定位 / 钉点 | 只靠标签弹出、没有位置关系变化；名称叠死 | 用地图移到目标并稳住，或用一条连线把关系画清楚。不要做成名片卡轮播 |
| 太空俯冲 | 俯向过程中露出黑区、未加载影像 | 先保证全程影像完整。做不到就改 Three.js 卫星地球，推向同一区域 |
| 太阳系 / 地月 / 行星 | 外行星出画；尺度让人误以为是真实星历 | 一次只看一对天体，或压缩距离但画面上按示意处理。不要假装仿真轨道 |
| 河流 / 流域 | 全网过密，主题河看不出 | 只画主题干流或该流域，其余弱化 |
| 海岸 / 海底 | 海底细节不足还继续下钻；接缝或空洞 | 停在 GEBCO / 海岸线能看清的尺度，或改成平面海岸图 |
| 灾害 / 专题 | 点位过密，底图或热力发糊 | 聚合、缩小范围，或改成单事件过程（震中涟漪、火点出现） |
| 地质 / 板块 | 没有可靠构造数据，却做成「写实地壳」 | 改用示意性块体或剖面，并收窄断言。没有依据就不要做这一镜 |
| 历史疆域 / 古道 | 没有经核验的历史数据 | 不要用现代 OSM 或现代国界硬演。改讲可核实的位置关系，或取消该镜 |
| 立体地形（任意） | 灰塑料山、没有地表层次；光影发平却要充当主镜头；近景发糊 | 铺公开地表覆盖或 Sentinel-2（距离要配得上纹理），需要重量时改 Blender 预渲。仍然发糊就拉远或改稳定俯视，不要假装近景实拍 |
| 水面 / 河道 | 只剩一条线，关系看不清；或近距离把示意水面写成真浪 | 用岸线或水体多边形成面。近景做不到真实水面就拉远，改俯视看清河道与岸线 |
| 立体立字 / 标牌 | 变成看不清的黑杠，或与字幕挤在一起 | 改用屏幕上的平面标签，并做避让。不要留着读不到的字 |
| 开场或收束 | 长时间黑场或无声；对准了无关区域；片尾留下空白 | 开场对准主题并尽快出现可见变化；剪掉片头片尾多余空白 |
| 画幅 | 竖屏把对比、山脉或流域挤得读不清 | 在用户指定画幅内重新构图、分段或减少信息；只有用户明确需要另一种比例时才另做版本 |
| 任意地理镜头 | 代表帧看起来粗糙、低级、抖动、缺瓦、发糊、发塑料、名不副实，或整体达不到能给观众看的完成度 | 按 `SKILL.md`：先换画法，再换讲法，再收窄表达。换完仍不合格就不要出这一镜 |

代表帧至少看开场、中段、结束。一眼发糊、发黑、发挤、发抖、发塑料，或整体达不到能给观众看的完成度，就按本表改，不要继续往下渲。
