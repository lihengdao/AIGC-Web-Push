# geo-viz · 地理与空间可视化

主镜头需要真实地理、位置或空间信息时加载；没有这类镜头就跳过。覆盖地图与行政区、位置与导航、路线与航班、地形与流域、地球与卫星、城市与建筑、太阳系与行星。

本技能的首要任务是**复用现成项目**，不是让 AI 每次重新发明地图引擎。只有现成项目缺少的薄适配层才写代码；不重复实现瓦片引擎、投影、DEM 解码、道路寻路或通用 GIS。

## 阅读顺序

1. 本 `SKILL.md`。
2. `references/projects.md`：确认现成项目、官方示例和成熟度。
3. `references/scenes.md`：按本镜任务选方案。
4. `references/data.md` 与 `references/storage.md`：数据许可、分辨率、获取与缓存。
5. `references/props-contract.md`：统一输入与资源路径。
6. 按宿主选择 `references/remotion.md` 或 `references/hyperframes.md`。
7. 需要数据裁切/投影转换时读 `references/preprocessing.md`。
8. 读 `references/quality.md` 与 `references/cameras.md` 设计并检查镜头。
9. 遇到画质或数据限制时读 `references/fallbacks.md`。
10. 出片前读 `references/checklist.md`。

## 硬规则

1. **免 Key 是默认路径，不是无限量承诺。** 默认方案不得依赖商业 API Key / Token。用户已授权提供本地数据或明确授权的服务时可以使用；必须遵守数据集许可、服务 ToS、额度、署名与再分发限制。
2. **先复用项目。** Remotion 地图镜头先看 Remotion 官方 MapLibre 示例与 `remotion-maps` technique；地图/建筑/轻量地形用 MapLibre 官方能力；复杂轨迹按需使用 deck.gl；高质量地形主镜头评估 BlenderGIS + 本地 DEM。实验项目不得标记为生产级。
3. **不从零造引擎。** 不从零实现瓦片引擎、地图投影、椭球地球、DEM 解码/重采样、大圆航线、道路寻路或完整建筑引擎。只写必要的数据适配、按帧控制、构图和视觉表达。
4. **参数化而非单地点写死。** 使用 WGS84/GeoJSON、`bbox`、`center`、数据、语言和样式配置。不得把某个国家/城市的数据或样式硬编码成唯一规则；确有地区差异时，用数据属性或明确配置表达，不滥用条件分支。
5. **按需取数并先查缓存。** 只获取本片镜头需要的范围、分辨率和图层。缓存命中就复用；缺失再从允许的数据源获取，并写入作品 `geo/` 与 `manifest.json`。
6. **规模化时不要依赖公共免费服务逐片供数。** 公共瓦片服务只用于符合条款的预览或用户主动下载；批量任务使用合法区域数据包、已授权自托管服务或版本化共享缓存。不得自动拆分请求来规避下载限制。
7. **渲染前资源完整。** DEM、纹理、矢量、路线和模型必须在渲染前本地化或放在获准的自托管源；最终逐帧渲染不依赖公共服务临时加载。
8. **时间轴决定运动。** Remotion 用 `useCurrentFrame()`；HyperFrames 用 seek。禁止用墙钟、CSS transition、`requestAnimationFrame` 或图库自带播放时钟驱动成片动画。
9. **历史地理须有依据。** 古道、古运河、古河道和历史疆域要有可追溯的历史数据；不得用现代 OSM/现代边界冒充历史。
10. **不伪装数据真实性。** 不得把 AI 生成画面或示意模型冒充真实卫星影像、实测地形、真实建筑或数字孪生。明确标识的概念示意可以使用，但不能当作地理证据。
11. **署名和许可随资产保存。** 记录来源、版本/日期、许可、CRS、分辨率、垂直基准和归属要求；要求署名时按数据许可展示。
12. **按本镜目标决定复杂度。** 不要求每个镜头都使用三维、卫星纹理、真实水面或 Blender。能把地理关系讲清楚且视觉完成度合格时，简单地图就是正确方案。
13. **质量不合格就换方案。** 先换画法，再换讲法或收窄表达；仍无法准确、清楚地呈现时取消该镜，不用粗糙结果凑数。

## Remotion 默认选型

| 需求 | 优先方案 | 采用条件 |
| --- | --- | --- |
| 平面地图、行政区、路线与点位 | Remotion 官方 MapLibre 示例 + MapLibre GL JS + Turf | 普通地理定位、路线讲解；优先固定地图底板加动态叠层 |
| 需要移动地图相机的路线镜头 | MapLibre + Remotion 按帧控制 | 必须先渲染短 MP4，检查 shimmer、瓦片闪烁和帧一致性 |
| 中远景三维地形地图 | MapLibre 官方 3D Terrain + 本地 DEM | DEM 覆盖和分辨率能够支撑该尺度 |
| 电影感山脉、峡谷、河谷 | 本地 DEM/纹理 + BlenderGIS/Blender 预渲 | 需要明显地形光影且预渲确实优于实时方案 |
| 城市建筑体量 | MapLibre `fill-extrusion` 或 Three.js | 有建筑足印/高度数据；清楚表达为体量示意，不冒充真实立面 |
| 地球与大圆航线 | MapLibre Globe 或 Three.js + Turf `greatCircle` | 样式化全球定位、航线；纹理必须本地化 |
| 大量轨迹、热力和流动数据 | deck.gl 图层叠加 MapLibre | 只有数据量和叙事确实需要时才引入 |

## 质量与交付

- 画面质量按 `references/quality.md`；镜头运动按 `references/cameras.md`。
- 资产放在作品 `geo/`，并维护 `manifest.json`；不把全球 DEM/OSM/瓦片打进技能包。
- 同一帧应可复现。先出代表帧和短 MP4，再进行完整渲染。
- 交付前通过 `references/checklist.md`，并遵守宿主视频规范。

本技能是可复用的工作流与选型说明，不包含第三方项目源码，不代表任何第三方项目已在当前环境安装或通过 MP4 测试。
